# Privacy — Open Emergency Handbook preview

No internet/location permission, account, analytics, advertising or subscription service. Reading, search, notes and checklist run locally. Household data stays in app-private preferences unless you explicitly export a plan. Export uses Android’s file picker and creates an unencrypted text file or JSON backup; choose a local folder for offline storage. Cloud file providers may upload it under their own policies. Exported copies remain after clearing app data. Android backup is disabled; device security and OS behaviour still matter.

The household screen can clear its data. Uninstalling/clearing app storage also removes it. The 112 action opens the dialler; it does not call automatically. External links open your browser, whose own privacy rules apply.

GitHub hosts source, releases and public feedback under its own policies. Do not post private information there. Version: 20 October 2026; reassess if features change.

Bookmarks, the last six opened guide IDs, language and reader-text preferences are also kept locally. The Saved screen can clear reading history; bookmarks are removed individually. Keeping the screen on is an explicit, session-only reading option and uses extra battery. It ends on leaving the reader or backgrounding the app.

JSON backups include the checklist, water-estimate inputs, notes and saved-guide IDs. Restore reads the selected file locally and requires confirmation before replacing these fields; language, reader settings and history are preserved. Invalid backups are rejected before replacement. Pending transfer data is held in memory across rotation; interrupted transfers should be retried and output files checked. Android cloud/device-transfer extraction rules exclude app storage. Exported files remain under the user-selected provider’s policies; encryption is not implemented.
